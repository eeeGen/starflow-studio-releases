2026.10.04 最新版本

1.4.6-rc

01 / 11
↗

素材目录按钮，始终看得见

素材路径再长，路径文字也会在可用空间内省略，右侧文件夹按钮保持可见、可点击。

管理版本与 Windows 文件版本已同步；安装包发布物复验通过。真实设备安装与功能验收仍待完成。

2026.10.04

1.4.5-rc

02 / 11

窗口更小，工作区仍从容

  • 缩小窗口时先收起左侧素材与最近文件栏，保留右侧商标和防盗水印工具。
  • 窗口进一步缩小至 760px 及以下时，两侧栏改为按需展开的抽屉；打开一侧会收起另一侧。

2026.10.04

1.4.4-rc

03 / 11

找素材，少绕一层目录

  • 素材和最近文件中的 image、image_* 目录改为显示对应的产品文件夹名；位于 output 下时，显示 output 的上级文件夹名。
  • 直接选择只有图片、没有子文件夹的素材目录，也可以扫描并生成。
  • 生成结果仍写入素材目录同级的 <原图目录>_logo，不会将输出目录误认为原图目录。

2026.10.02

1.4.3-rc

04 / 11

外部改图，由你决定

  • 生成前发现输出图片被其他程序修改时，列出受影响文件，并提供“取消”“保留并跳过”“覆盖并重新生成”三种选择。
  • 保留冲突图片时，其余图片继续处理；覆盖后的旧图片可通过“撤回”恢复。
  • 执行覆盖前再次核对文件内容，避免使用过期的确认结果。

2026.10.02

1.4.2-rc

05 / 11

删掉输出图，可以重新生成

  • 手动删除 image_logo 中的图片后，可按现有商标与防盗水印设置重新生成，无须删除配方。
  • 仍存在但内容已被外部修改的图片继续受到保护，不会因刷新素材卡而被静默覆盖。
  • 撤回重新生成操作时，恢复到图片原本不存在的状态。

2026.10.02

1.4.1-rc

06 / 11

操作更连贯，夜间更统一

  • 移除工作区顶部重复的绿色进度文字。
  • 在“调整防盗水印”和“调整商标”之间切换时，尽量停留在当前图片。
  • 导出诊断包后自动打开所在文件夹；夜间模式滚动条也改为深色。
  • 结合事件日志排查商标编辑错误，并确认 1.4.0 的两次相关操作成功记录。

2026.10.02

1.4.0-rc

07 / 11

工作台，进一步精简

  • 素材与最近文件区域按固定比例排布，各自独立滚动；最近文件沿用素材列表样式，并在正常关闭软件时清空。
  • 移除“单产品工作台”标题、当前产品路径外框和重复的模式提示，保留可见的当前产品路径。
  • 预览模式改为“调整防盗水印”“调整商标”；撤回移至预览顶部，暂不可用的星门移至主题切换左侧，右侧 Logo 工具区与左侧栏顶部对齐。
  • 点击当前 Logo 卡片即可选版本，减少额外下拉菜单；逐张防盗水印模式保留预览深浅滑块。
  • 修复打包版调整商标后因位置数据类型不符而保存失败的问题。

2026.10.02

1.3.0-rc

08 / 11

围绕单产品，重做主工作流

  • 左侧为可收起的全高素材与最近文件栏，中间为自适应预览区，右侧为商标和防盗水印工具；窄窗口下可展开侧栏抽屉。
  • 左侧底部显示版本、版权和状态灯；素材刷新改为圆形图标，移除多余的“素材根目录”文字。
  • 产品路径、运行状态和撤回收进现有区域，减少页面纵向占用。
  • “减淡 / 加深 / 通过”及快捷键 1 / 2 / 3 仅在逐张调整防盗水印时启用，不再触发旧版批量评分行为。
  • 星门的界面及后端入口暂时禁用，内部实现保留；移除 Ctrl+K 命令面板与主页“保存设置”，相关设置自动保存。

2026.09.30

1.2.0-rc

09 / 11

出问题时，有迹可循

  • 增加本地结构化事件记录，涵盖关键操作、界面异常与后台处理；报错时显示诊断编号。
  • 工作台和许可证页面提供手动导出诊断包。事件记录最多保留 7 天、总量不超过 50 MB，不会自动上传。
  • 事件记录不包含图片内容、完整路径、文件名和许可证数据。

2026.09.29

1.1.0-rc

10 / 11

商标，从批量到逐张微调

  • 生成后可逐张拖动商标、通过角点或滑块缩放，并明确保存当前图片；未编辑的图片仍可直接使用。
  • 商标版本选择器加入透明背景缩略图和较大预览；位置保存在图片配方中，重新打开后可继续调整。
  • 保存商标时保留已有防盗水印；两类水印统一输出到各素材文件夹同级的 <素材文件夹>_logo，按配方重新合成。
  • 增加单次操作撤回和异常写入恢复。
  • 增加星门内部多产品处理实现；其入口已在 1.3.0-rc 暂时关闭。

2026.08.14 起

1.0.6-rc 及早期基础

11 / 11

稳定运行的起点

  • 修复逐张微调时快捷键 1 / 2 / 3 与“减淡 / 加深 / 通过”按钮行为不一致的问题。
  • 修复启动时偶发停在“等待 WebView Bridge”的问题；“重试连接”会在当前页面重新探测，并增加 Windows 单实例保护。
  • 固定已验证的 WebView 依赖版本，完善启动日志和运行时诊断。
  • 产品更名为 StarFlow STUDIO，加入离线签名许可证、设备请求、完整性检查与发布包复验流程。
  • 增加许可证及发布清单公钥指纹校验、生成与保存操作的统一授权检查，以及安装包 SHA-256 记录。
