2026.10.04 最新版本

1.4.6-rc

01 / 11
↗

常用入口，始终顺手

修复按钮消失问题。

路径再长，所有按钮也会留在你看得见、点得到的位置。完整路径仍可查看，长路径不再挤走常用操作。

2026.10.04

1.4.5-rc

02 / 11

小窗口，也能专注当前图片

  • 新增双面抽屉式机制。
  • 缩小窗口时，素材与最近文件栏会先收起，商标和防盗水印工具继续留在手边，预览区域优先获得空间。
  • 窗口更窄时，两侧工具栏可按需展开。打开其中一侧，另一侧会自动收起，避免遮住正在查看的图片。

2026.10.04

1.4.4-rc

03 / 11

任意图片目录，开盒即用

  • 素材列表和最近文件优先显示产品名称，减少一排排 image、image_* 带来的辨认成本。
  • 增加叶子目录扫描功能，无须退回父级路径扫描。

2026.10.02

1.4.3-rc

04 / 11

外部修改的图片，去留由你掌控

  • 如果输出图被其他软件改过，再次生成前会列出受影响的图片。你可以取消操作、保留这些图片并继续处理其他图片，或明确选择覆盖重做。
  • 选择覆盖后仍可使用“撤回”找回原图。真正写入前，自动复核机制还会再核对一次文件；如果你确认后文件又变了，不会沿用过期的决定直接覆盖。

2026.10.02

1.4.2-rc

05 / 11

对于删掉的成品图，我们提供了后悔药

  • 手动删除不满意的成品图后，可以沿用已经选好的商标、防盗水印和调整记录重新生成，无须从头配置整个产品。
  • 对仍然存在、但内容已被其他软件改动的图片，软件会继续保护；刷新素材也不会悄悄覆盖它们。
  • 撤回一次重新生成后，图片会回到生成前“文件不存在”的状态，避免留下你本来已经删除的成品。

2026.10.02

1.4.1-rc

06 / 11

操作不断档，细节更统一

  • 在“调整防盗水印”和“调整商标”之间切换时，保持当前图片，不用每次从第一张重新找起。
  • 导出诊断包后，文件所在位置会自动打开。
  • 夜间模式下的滚动条也会随界面变为深色。
  • 工作区移除了重复的进度文字，让当前图片和真正需要的操作更醒目。

2026.10.02

1.4.0-rc

07 / 11

让主工作台回到图片本身

  • 素材与最近文件区域按固定比例排布，各自独立滚动，查找素材时不会把另一组内容一起带走。
  • 最近文件沿用素材列表样式，统一视觉。
  • 最近文件在正常关闭软件时清空，下次打开从干净的列表开始。
  • 当前产品路径继续可见，重复的标题和模式提示被收起，为图片预览腾出空间。
  • 缩短交互路径：
    • “调整防盗水印”“调整商标”两个入口直接对应手头任务；
    • 撤回就在预览区顶部；
    • 右侧栏中，点击当前 Logo 卡片即可切换版本，少走一次下拉菜单。
  • 逐张调整防盗水印时，可以用滑块预览当前图片的深浅；商标位置调整完成后也能正常保存。
  • 修复打包版调整商标后因位置数据类型不符而保存失败的问题。

2026.10.02

1.3.0-rc

08 / 11

围绕单产品，重做主工作流

  • 优化交互设计。
  • 左侧集中查看素材与最近文件，中间专心预览，右侧调整商标和防盗水印。侧栏可手动收起，窄窗口下也能按需展开。
  • 产品路径、运行状态和撤回操作融入现有区域，减少上下滚动。
  • 移除多余元素，工作流程更专注。
  • 素材刷新改为紧凑的圆形按钮，视觉更美观。
  • BUG修复：“减淡”“加深”“通过”及数字键 1、2、3 只在调整防盗水印时生效。查看成品或调整商标时，不会误触发旧的逐张处理动作。
  • “星门”暂时不可进入，内部等待装修后重新开放。
  • 主页设置新增自动保存机制，无须再找“保存设置”。
  • 优化缓存机制，不再留下乱七八糟的废弃版本文件和中间文件，使你的工作区和资产库都保持整洁有序。

2026.09.30

1.2.0-rc

09 / 11

遇到问题，有迹可循

  • 增加本地结构化事件记录，涵盖关键操作、界面异常与后台处理；报错时显示诊断编号。
  • 需要协助排查时，你可以手动导出诊断包。记录不会自动上传，也不包含图片内容、完整路径、文件名或许可证数据等隐私信息；本机记录按时间和容量自动限额保存。

2026.09.29

1.1.0-rc

10 / 11

商标从批量处理，走向逐张精修

  • 批量生成后，可以单独拖动某张图片上的商标，或通过角点与滑块调整大小；满意后再保存这张图片，其他图片不用跟着重做。
  • 选择商标版本时可以直接看透明背景缩略图和大图。每张图片的调整位置会被记住，再次打开仍能接着改。
  • 调整商标时，已加上的防盗水印会保留。两者按同一张图片的保存设置重新合成，避免反复编辑时层层叠加。
  • 单次操作可以撤回；写入意外中断时也增加了恢复处理。
  • 增加星门进入多产品处理界面；其入口已在 1.3.0-rc 暂时关闭。

2026.08.14 起

1.0.6-rc 及早期基础

11 / 11

稳定工作的基础

  • 逐张调整时，快捷键 1、2、3 与“减淡”“加深”“通过”按钮保持一致。
  • 修复启动时偶发停在“等待 WebView Bridge”的问题；“重试连接”会在当前页面重新探测，并增加 Windows 单实例保护。
  • 固定已验证的 WebView 依赖版本，完善启动日志和运行时诊断。
  • 产品正式取名 StarFlow STUDIO，并建立离线许可证验证机制；无需每次处理图片都连接网络验证授权。
  • 许可证和发布清单使用数字签名与指纹校验，完善完整性检查与发布包复验流程。

安装前请留意

  • 当前为 Windows x64 RC 候选版，真实设备安装和功能验收尚未完成。
  • 使用前请备份重要图片与工作数据；软件更新不会自动备份你的文件。
  • 建议一个产品使用一个独立文件夹，原图集中放在 image 或 image_* 中，例如： 
    产品素材/
└─ 产品 A/
   └─ output/
      ├─ image/         原图
      ├─ image_ml/      其他原图（可选）
      ├─ image_logo/    生成的成品图
      └─ image_ml_logo/ 其他成品图
    _logo 文件夹由软件在原图文件夹旁生成，无须预先建立。也可以直接选择只有图片的目录开始处理；此结构仅供整理素材时参考。
